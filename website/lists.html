The HPComm project would like to express their gratitude to Mr. John Goertzen of complete.org, for hosting the HPComm mailing lists.

These mailing lists are driven by the LISTARGATE program at http://www.complete.org. This page offers you an alternative (and easier) way to subscribe and unsubscribe from the HPComm mailing lists than the email-based or web-based approach that LISTARGATE usually uses.

At present, there are four mailing lists.
hpcomm@complete.orgGeneral mailing list for discussing the use of HPComm.
hpcomm-dev@complete.orgDiscussion list for HPComm developers and bug reports.
hpcomm-announce@complete.orgAnnouncements of new software versions and bug fixes. Low volume.
hpcomm-cvs@complete.orgNotification of code changes go to this list.
