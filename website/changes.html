HPComm.org Change list
Last modified: Sat Jun 17 15:59:21 EST 2000

Changes:

Here are the changes, bug fixes and improvements in the latest version of HPComm and HPComm38.

HPComm:

Here are the changes to HPComm from 3.0r3 to 3.0r4:

  • Fixed a problem where the transfer of a file from the PC to the calculator would fail under certain circumstances.
  • Fixed a problem where refreshing HPComm would cause the report of a protocol error.
  • Fixed a problem where the file icon would go blank when renaming a file on the calculator.
  • When a directory is re-read, make sure that the current directory on the calculator matches the one on the PC.
  • Fixed a problem when translation Mode 0 was set, where the first entry was not shown.
  • When a file on the PC is renamed, the icon must be recalculated.
HPComm38:

Here are the changes to HPComm38 from 1.0r3 to 1.0r4:

  • HPComm38 now works with the HP39G and HP40G, as well as the HP38G.
  • Fixed a problem where HPComm38 was incorrectly handling the initialisation of new directories.
  • Changed the way HPComm38 reports errors - now they're part of the main dialog, rather than an error popup.
  • Improved the ability to handle some classes of error when communicating with the calculator.
